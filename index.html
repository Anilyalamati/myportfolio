Deepfake Detection Web Application

An applied computer-vision and web project exploring how synthetic or manipulated images and video frames can be inspected through a clean media-upload interface and structured analysis pipeline.

Problem Explored

Rapid advances in generative facial synthesis make visual verification difficult for everyday users, motivating accessible interfaces that break down media inspection into understandable steps.

Detection Workflow

Accepts uploaded image or video files, extracts facial regions across keyframes, preprocesses inputs for deep-learning / computer-vision inspection, and presents structured visual feedback in the browser.

Key Technical Challenges

Distinguishing heavy social-media video compression artifacts from genuine manipulation traces, maintaining consistency across varying lighting conditions, and handling frame-extraction latency cleanly.

Technologies Explored & Used

Python Computer Vision / Image Processing Deep Learning Feature Extraction Web Media Upload Interface

PROJECT 03 // APPLIED MACHINE LEARNING
DATA EXPLORATION & SIMILARITY RANKING SYSTEM

Machine-Learning Recommendation System

A practical machine-learning project focused on transforming structured datasets and item attributes into relevant, personalized Top-N recommendations through feature engineering and vector similarity modeling.

Objective

Explore how content attributes and interaction signals can be represented mathematically in vector space to retrieve relevant items without relying on manual rules.

Approach & Dataset Work

Covers data cleaning, missing-value handling, text/attribute tokenization, vectorization, and pairwise cosine similarity computation to rank candidate recommendations.

Evaluation & Inspection

Evaluated by inspecting feature-space alignment, Top-N relevance consistency across diverse seed queries, and cold-start behavior on sparse item metadata.

Technologies Used

Python Pandas & NumPy Scikit-Learn Cosine Similarity / Vectorization Exploratory Data Analysis

DATA SCIENCE WORKFLOW

From Raw Dataset to Ranked Candidates

01 // DATA INGESTION & CLEANING

Deduplicating records, handling null metadata fields, and standardizing categorical tags in Pandas.

02 // FEATURE VECTORIZATION

Converting combined item attributes and descriptors into normalized high-dimensional numerical vectors.

03 // SIMILARITY COMPUTATION

Computing cosine similarity matrices to measure angular closeness between seed items and candidates.

04 // TOP-N FILTERING

Sorting similarity scores and returning ranked recommendations for downstream inspection.
